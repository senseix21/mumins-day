# Context

Everything a person or an agent needs to pick this project up cold. Read in this order:

1. `STATE.md`: where things stand and what is next.
2. `GAPS.md` and `QUESTIONS.md`: what is undecided.
3. `spec/01-constraints.md`: the invariants every change must keep.
4. The rest of `spec/` as the task needs.
5. `LOG.md`: history, when you need to know why something is the way it is.

Rules for keeping it current are in `../CLAUDE.md` under "Start and end of every task".
